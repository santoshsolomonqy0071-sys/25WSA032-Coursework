Task 2 - Arduino Temperature Monitoring
A smart temperature monitoring system built using an arduino and a sensor. It reads temperature depending on its mode. Them it applies DFT to find dominant frequncy. Then uses moving averages to smooth variation over time. After that it switched between the differenct modes based on the temperature. Sends data to PC for analysis

Task 3 - Pizza Delivery Bot Optimisation
Optimises a fleet of 9 delivery bots, 3 of 3 differenet kinds, robots, droids and drones. We are required to improve per bot charging threshols, nearest charging selection, opportunistic charging when passing by a charger. Choosing the nearest pizza instead of the first one found, so that heavier pizzas can be added. Finally a KPI comparison. 


Task 4 - Temperature Data Analysis
